# Блок 1. База Python для собеседования

Уровень: Junior / Junior+ / Middle- на Python-бэкенд. Срок блока: 1–2 дня.

Здесь нет готовых ответов. По каждому пункту: проверить руками в интерпретаторе, объяснить вслух своими словами, сохранить рабочий фрагмент в файл с тем же номером (`01_mutability.py` и дальше).

Запуск из этой папки:

```powershell
cd "C:\Users\dunice\Desktop\learning python\03-interview\01-language"
python
```

Приглашение `>>>` — это интерпретатор. Выход: `exit()`.

- [ ] **1. Изменяемые и неизменяемые типы.** Возьмите `int`, `str`, `tuple` и `list`, `dict`, `set`. Попробуйте изменить каждый после создания. Зафиксируйте, какие операции создают новое значение, а какие меняют тот же объект. Смотрите `id(...)` до и после.
- [ ] **2. Опасный аргумент по умолчанию.** Напишите `def f(x, items=[])`, дважды вызовите функцию и добавьте элемент в `items`. Сравните, тот же это список или новый. Найдите безопасную замену значения по умолчанию.
- [ ] **3. Присваивание и копии.** Выполните `a = [1, 2]`, `b = a`, `b.append(3)`. Что в `a`? Отдельно попробуйте поверхностную копию и `deepcopy` на вложенном списке.
- [ ] **4. `is` и `==`.** Сравните одинаковые значения через `==` и через `is`. Проверьте маленькие числа и числа побольше. Сформулируйте, что сравнивает каждый оператор.
- [ ] **5. Ключи словаря.** Попробуйте сделать ключом `list` и ключом `tuple`. Объясните, почему один вариант принимается, а другой нет.
- [ ] **6. Как устроен `dict`.** Объясните, за счёт чего поиск по ключу в среднем O(1). Проверьте, в каком порядке `dict` отдаёт ключи, если вставлять их не по алфавиту.
- [ ] **7. `set`.** Заведите два множества и выполните `&`, `|`, `-`. Сформулируйте, чем множество отличается от списка, если нужна проверка «элемент уже есть».
- [ ] **8. `*args`, `**kwargs`, распаковка.** Напишите функцию, которая принимает произвольные позиционные и именованные аргументы. Вызовите её, распаковав список через `*` и словарь через `**`.
- [ ] **9. Comprehension.** Запишите одно и то же преобразование циклом и через list comprehension, затем dict comprehension и set comprehension.
- [ ] **10. Срезы и отрицательные индексы.** На списке и строке попробуйте `[0]`, `[-1]`, `[1:4]`, `[:3]`, `[::2]`, `[::-1]`. Скажите, что означает каждый индекс.

Когда все пункты отмечены и по каждому есть файл с примером, блок готов к разбору.
